# 🍪 Midnight Bakery Runner

เกม endless runner วาดด้วย Canvas 2D ล้วน ไม่มีไฟล์ asset สักไฟล์ — กราฟิกวาดด้วยโค้ด เสียงสังเคราะห์ด้วย Web Audio API

## รันยังไง

```bash
npm install
npm run dev
```

เปิด http://localhost:5173

คำสั่งอื่น:

```bash
npm run build      # สร้างไฟล์สำหรับขึ้นเว็บจริง ลงในโฟลเดอร์ dist/
npm run preview    # ทดสอบไฟล์ที่ build แล้ว (ควรทำก่อน deploy เสมอ)
```

## บัญชีผู้เล่น

ลำดับหน้าตอนเปิดเกม:

```
หน้าชื่อเกม ──[เข้าเกม]──┬─ มีบัญชีแล้ว ───────────────────► ล็อบบี้
                          │
                          └─ ยังไม่มี ─► เข้าสู่ระบบ ─► ตั้งชื่อตัวละคร ─► ล็อบบี้
```

| ปุ่ม | ทำอะไร |
|---|---|
| เล่นแบบผู้มาเยือน | สร้างบัญชีให้เงียบ ๆ ไม่ต้องกรอกอะไร — แต่ล้างเบราว์เซอร์แล้วหาย |
| เชื่อมอีเมล (ในหน้าตั้งค่า) | ผูกอีเมลกับบัญชีเดิม ของทุกอย่างอยู่ครบเพราะ user id ไม่เปลี่ยน |
| เข้าด้วยอีเมล | ดึงบัญชีเดิมกลับมาบนเครื่องใหม่ — ของในเครื่องนี้จะถูกแทนที่ |

ทั้งสองงานที่ใช้อีเมลยืนยันด้วย **รหัส 6 หลัก** ไม่ใช่ลิงก์ในเมล เพราะบนมือถือลิงก์จะเปิด
ในเบราว์เซอร์ของแอปเมล ซึ่งคนละที่กับแท็บที่เปิดเกมค้างไว้ แล้ว session จะไปลงผิดที่

**ตั้งค่า Supabase ก่อนใช้งาน** (ไม่ตั้งก็เล่นได้ แค่เก็บข้อมูลในเครื่องอย่างเดียว):

1. Authentication → Sign In / Providers → **เปิด Anonymous Sign-Ins**
2. Authentication → Sign In / Providers → **เปิด Email**
3. Authentication → Emails → Templates → ใส่ `{{ .Token }}` ลงในแม่แบบ **Magic Link**
   และ **Change Email Address** — ข้อนี้ลืมบ่อย แม่แบบเริ่มต้นส่งไปแต่ลิงก์ ไม่มีรหัสให้กรอก
4. SQL Editor → วาง `supabase/schema.sql` ทั้งไฟล์ → Run
5. คัดลอก `.env.example` เป็น `.env` แล้วใส่ URL กับ anon key → รีสตาร์ต `npm run dev`

## วิธีเล่น

| ปุ่ม | ทำอะไร |
|---|---|
| `Space` / `↑` / `W` / แตะจอ | กระโดด (กดซ้ำกลางอากาศ = กระโดดสองชั้น) |
| กดค้าง `↓` / `S` | หมอบลอดใต้คาน (กดกลางอากาศ = ดิ่งลงเร็ว) |

## กฎที่ตั้งไว้ (อย่าเผลอทำผิด)

1. **ไฟล์ตรรกะห้าม import `ctx`** — `player.js`, `level.js`, `game.js` (ยกเว้นเมธอด `draw`) ไม่ควรรู้จักการวาด ทำให้วันหนึ่งย้ายไป Phaser แล้วเอาไปใช้ต่อได้เลย

2. **`player.y` คือตำแหน่ง "เท้า" ไม่ใช่หัว** — เพราะเท้าอยู่ที่เดิมเสมอไม่ว่าจะยืนหรือหมอบ ถ้าเก็บเป็นขอบบน การเช็คพื้นจะพังทันทีที่ความสูงเปลี่ยน

3. **ทุกค่าที่บวกในลูปอัปเดตต้องคูณ `dt`** — ไม่งั้นเกมจะเร็วต่างกันระหว่างจอ 60Hz กับ 144Hz

4. **ตัวเลขที่จูนบ่อยต้องอยู่ใน `config.js`** — อย่าฝังตัวเลขไว้กลางโค้ด เดี๋ยวหาไม่เจอ

5. **ของที่หลุดจอต้องถูกลบ** — ดู `Level.cull()` ถ้าลืม array จะโตไม่หยุดจน FPS ตก

## แนวคิดสำคัญ 3 อย่าง

**1. ตัวละครไม่ได้วิ่งจริง** — `PLAYER_X` ตรึงอยู่ที่ 170 ตลอด สิ่งที่ขยับคือ `camera` ทุกอย่างในโลกเก็บพิกัดจริง ตอนวาดค่อยลบ `camera` ออก นี่คือ pattern มาตรฐานของเกม runner ทุกเกม

**2. ด่านสุ่มจาก "ท่อน" ไม่ใช่สุ่มทีละชิ้น** — ถ้าสุ่มหนามทีละอันจะได้ด่านที่ผ่านไม่ได้ ให้ออกแบบท่อนที่การันตีว่าผ่านได้แล้วสุ่มต่อกัน ดู `PATTERNS` ใน `level.js`

**3. ความยากมาจากความเร็ว ไม่ใช่จากด่าน** — `SPEED.gain` เพิ่มความเร็วทุกเฟรม ทำให้ด่านชุดเดิมยากขึ้นเรื่อย ๆ โดยไม่ต้องออกแบบเพิ่ม

npm i -g vercel
