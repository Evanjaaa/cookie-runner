# ช่องวางภาพท่าคว้า (บอสกล้วยราคี)

วางไฟล์ SVG จากนักวาดไว้ในโฟลเดอร์นี้ เกมจะใช้ไฟล์นั้นแทนท่าชั่วคราวเอง ไม่ต้องแก้โค้ด
(หน้าเทส: `gameplay-lab.html` โหมด "🍌 บอสกล้วย" และ `monster-lab.html` บอสกล้วยราคี)

## ตั้งชื่อไฟล์

- ขึ้นต้นด้วยรหัสช่อง แล้วตามด้วยชื่ออะไรก็ได้ เช่น `B2-grab-low.svg`
- ท่าที่มีหลายเฟรม ให้ใส่เลขท้ายไฟล์ เช่น `C2-struggle-1.svg` `C2-struggle-2.svg` … (เรียงตามเลข เล่น 8 เฟรม/วิ)
- ลูกสมุนวิ่งตาม 4 เฟรม ใช้รหัส `M1` ถึง `M4` คนละไฟล์

## ท่าที่แขนยืด (B2 B3 B4 B5 B6 B8)

- ไม่ต้องวาดแขนซ้ายในตัว โค้ดยืดท่อนแขนจากไหล่ไปถึงน้องเอง
- วาดมือแยกไว้ในกลุ่ม `<g id="hand">` มือแบ (B2–B4) ให้ชี้ไปทางซ้าย โค้ดหมุนตามทิศแขนเอง
- B5 B6 B8 (กำมือ): เว้นช่องในกำมือไว้ โค้ดวางน้องลงไปเอง ใช้ได้ทุกสกิน
