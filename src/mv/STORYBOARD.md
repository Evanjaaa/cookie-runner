## A. Master Story

เช้าวันหนึ่งในบ้านหลังเล็ก **น้องส้ม** ลูกแมวส้มตัวเดียวกับในเกม ขดตัวหลับอยู่บนเบาะริมหน้าต่างบานใหญ่
แดดเช้าส่องเป็นลำ ฝุ่นเล็ก ๆ ลอยในแสง ผ้าม่านพลิ้วตามลม น้องส้มค่อย ๆ ลืมตา หาวกว้าง
ยืดตัวสุดแขน แล้วขดกลับไปนอนต่อ เจ้าของเดินมาลูบหัว น้องส้มเคลิ้มหลับตา
แต่พอลูบซ้ำรอบสอง น้องส้มใช้อุ้งเท้าดันมือออกเบา ๆ แล้วหันหลังให้ — *รักนะ แต่ขอนอนก่อน*

เสียงกรุ๊งกริ๊งจากในครัว หูตั้งทันที น้องส้มวิ่งผ่านห้องนั่งเล่น ลอดประตูโค้ง ผ่านโต๊ะกินข้าว
ไปนั่งตัวตรงหน้าชามข้าว หางกระดิกตามจังหวะ ร้องเมี้ยวครั้งหนึ่ง เจ้าของยังไม่หัน ร้องอีกครั้ง
แล้วเอาเท้าแตะชามดังกริ๊ง ๆ เจ้าของหัวเราะแล้วเทอาหารให้ น้องส้มเพิ่งได้กินสองคำ
กริ่งหน้าบ้านก็ดัง เจ้าของเดินออกไป น้องส้มมองชาม มองเจ้าของ... แล้วเลือกวิ่งตามเจ้าของ

สำหรับคน มันคือการเดินไปเปิดประตูธรรมดา แต่สำหรับน้องส้ม ขาเจ้าของสูงเหมือนต้นไม้
โต๊ะกินข้าวคืออุโมงค์ ขาเก้าอี้คือป่า น้องส้มวิ่งซิกแซกลอดขาเก้าอี้ เจ้าของเดินเร็วขึ้น
น้องส้มก็วิ่งเร็วขึ้น จนเจ้าของหยุดที่หน้าประตู น้องส้มเบรกไม่ทัน ชนน่องเจ้าของเบา ๆ แล้วเงยหน้ามอง

เจ้าของรับพัสดุ ถือกล่องกระดาษกลับเข้าห้องนั่งเล่น แกะของออก แล้ววางกล่องเปล่าที่มีกระดาษยับ ๆ
ทิ้งไว้บนพรมหน้าโซฟา ก่อนเดินกลับเข้าครัว น้องส้มเอียงหัวมองกล่อง ดม แตะ มุดหัวเข้าไป
แล้วกระโดดลงไปทั้งตัว — กล่องธรรมดาใบนั้นกลายเป็นหีบสมบัติลับ มีกระดาษยับเป็นเพื่อนเล่น
ตบ กระโจน กลิ้ง กัด จนกระดาษปลิวออกมานอกกล่อง

**ปัง!** กระทะหล่นในครัว น้องส้มแข็งทื่อ ขนพอง แล้วค่อย ๆ จมหายลงไปในกล่องจนเหลือแค่หูกับตา
เจ้าของรีบเดินมา คุกเข่าข้างกล่อง ยื่นมือต่ำ ๆ ให้ดมแล้วรอ น้องส้มดม ค่อย ๆ ปีนออกมา
เอาหัวถูมือ ขนยุบลง สงบลงอีกครั้ง

เจ้าของไปนั่งที่โซฟา น้องส้มมองจากพื้น ย่อตัว ส่ายก้น แล้วกระโดดขึ้นโซฟา เดินวนรอบหนึ่ง
นั่งลงข้าง ๆ เพลงเงียบลง มือเจ้าของลูบหัว น้องส้มหลับตาครางเบา ๆ แล้วขดตัวลงข้างขาเจ้าของ
กล้องถอยออกช้า ๆ ให้เห็นทั้งห้อง: เบาะใต้หน้าต่างที่ว่างแล้ว แดดที่ขยับสูงขึ้นกว่าตอนเช้า
กล่องกระดาษกับกระดาษยับบนพื้น — ทั้งหมดเกิดในบ้านหลังเดียวกัน ในเช้าเดียวกัน

## E. Environment Continuity — ผังบ้าน (ใช้ตลอดทั้ง MV)

บ้านเป็น **แถบยาวแถบเดียวต่อกันจากซ้ายไปขวา** กล้องเลื่อนไปตามแถบนี้เสมอ
ของทุกชิ้นมีตำแหน่งตายตัว (หน่วยโลก: 1 หน่วย ≈ 3 มม. · ลูกแมวยืนสูงราว 50 หน่วย)

```
  ← ซ้าย                                                                          ขวา →
 ┌──────────── ห้องนั่งเล่น ────────────┐┌──── โถง/ห้องกินข้าว ────┐┌──── ครัว ────┐
 │ [หน้าต่างบานใหญ่]      [โซฟา]   พรม  ││  ประตู   [โต๊ะกินข้าว]  ││ เคาน์เตอร์   │
 │  ม่านซ้าย-ขวา                         ⌒  หน้าบ้าน  เก้าอี้ 2 ตัว ⌒  เตา ชั้นวาง  │
 │ [ม้านั่งริมหน้าต่าง+เบาะแมว]  (จุดวางกล่อง)│                         ││  ชามข้าวแมว  │
 └───────────────────────────────────────┘└─────────────────────────┘└──────────────┘
   x: 0 ─── 360        700 ── 1150  1250   1400 (ประตูโค้ง) ... 2400 (ประตูโค้ง) ... 3200
```

| ของ | ที่อยู่ | หมายเหตุความต่อเนื่อง |
|---|---|---|
| หน้าต่างบานใหญ่ + ม่าน | ห้องนั่งเล่น ซ้ายสุด | แหล่งแสงเดียวของเรื่อง ลำแสงเอียงลงขวา มุมแสงค่อย ๆ ชันขึ้นตามเวลา (เช้า → สายขึ้น) |
| ม้านั่งริมหน้าต่าง + เบาะกลม | ใต้หน้าต่าง | ฉาก 1 แมวนอนตรงนี้ · ฉาก 6 เบาะว่าง |
| โซฟา | ห้องนั่งเล่น กลางห้อง | ฉาก 6 |
| พรมหน้าโซฟา | ระหว่างโซฟากับประตูโค้ง | ฉาก 4 วางกล่องตรงนี้ · กล่องอยู่ที่เดิมจนจบ |
| ประตูโค้ง 1 | ห้องนั่งเล่น → โถง | ทางผ่านเดียวระหว่างสองห้อง |
| ประตูหน้าบ้าน | โถง ฝั่งซ้าย | ฉาก 3 เจ้าของหยุดตรงนี้ |
| โต๊ะกินข้าว + เก้าอี้ 2 ตัว | โถง ฝั่งขวา | ฉาก 2 วิ่งผ่าน · ฉาก 3 วิ่งลอด |
| ประตูโค้ง 2 | โถง → ครัว | |
| ชามข้าวแมว | ครัว บนพื้นหน้าเคาน์เตอร์ | ฉาก 2 |
| เตา + กระทะ | ครัว | ฉาก 5 ต้นเสียงปัง (อยู่นอกจอตอนดังเสมอ) |

**กฎทิศทาง:** ไปทางครัว = วิ่งไปทางขวาของจอเสมอ · กลับห้องนั่งเล่น = ไปทางซ้ายเสมอ
เสียงจากครัวจึงมาจากขอบขวาของจอทุกครั้ง คนดูเดาได้เองว่าเสียงมาจากไหนโดยไม่ต้องบอก

## ตัวละคร

**น้องส้ม** — ตัวเอกของเกมตัวเดิม (สกิน "ส้มน้อย") วาดด้วยโค้ดชุดเดียวกับในเกม
ส้มสด มีลายที่หลังกับหน้าผาก อกครีม ปลายหางครีม · ใช้ตัวเดียวตลอด ไม่มีการวาดใหม่ระหว่าง Shot
(เนื้อเพลงในบรีฟบอกขาวดำ แต่ตกลงใช้น้องส้มตามเกม)

**เจ้าของ** — ไม่เห็นหน้าเลยทั้งเรื่อง เห็นแค่ มือ + แขนเสื้อ, ขา + กางเกง + รองเท้าแตะหูแมวสีชมพู
เสื้อไหมพรมสีเทาอมม่วง กางเกงยีนส์ รองเท้าแตะสีชมพูหูแมว — ชุดเดิมตลอดเรื่อง
มองจากระดับสายตาแมวเสมอ ขาเจ้าของจึงสูงเกือบเต็มจอ

> ปรับจากบรีฟ: ไม่มีช่วงเดินช้าแล้วเร่ง — เดินตามความเร็วคงที่ต่อจากฉาก 2 · หลังชนขาเจ้าของ น้องหันไปนั่งมองประตู (หันหลังให้กล้อง) แล้วเงยมองเจ้าของตอนเพลงเงียบ

**3.1 · 0:30–0:33** — POV ลูกแมว
- D: กล้องติดพื้น ซูมเข้า ขาเจ้าของสูงจนหลุดขอบบนจอ โต๊ะกินข้าวเป็นอุโมงค์ ขาเก้าอี้เป็นป่า
- C: แมววิ่งเหยาะ ๆ เข้าเฟรมจากขวา

**3.2 · 0:33–0:37** — ไล่ตามในป่าขาเก้าอี้ (พีคของเพลง)
- C: เจ้าของเดินเร็วขึ้น แมววิ่งเร็วขึ้น ซิกแซกลอดขาเก้าอี้ (ผ่านหลังขาหนึ่ง หน้าขาหนึ่ง) กระโดดข้ามรองเท้าแตะ
- D: Tracking เร็ว ฉากหน้าเบลอผ่านเป็นจังหวะ

**3.3 · 0:37–0:40.5** — เบรกไม่ทัน

- D: Medium ระดับพื้น

**3.4 · 0:40.5–0:42.5** — (เพลงเงียบ) เงยหน้ามอง
- C: เงยหน้ามองขึ้นไปสุดขาเจ้าของ "?" หางปัดพื้นช้า ๆ
- D: Low Angle มองขึ้น เจ้าของตัวสูงลิบ แสงจากประตูที่กำลังเปิดส่องเป็นขอบ
- G: ประตูเปิด แสงขาวจากนอกบ้านเต็มจอแว้บหนึ่ง → ฉาก 4

### SCENE 04 — THE SECRET TREASURE (0:42.5–1:02) · สนุกที่สุด

**4.1 · 0:42.5–0:45.5** — กล่องพัสดุ
- C: เดินข้างขาเจ้าของ เงยหน้ามองกล่องที่เจ้าของถือ
- เรื่อง: เจ้าของเดินกลับห้องนั่งเล่น (ไปทางซ้าย) คุกเข่า แกะของออก วางกล่องเปล่าที่มีกระดาษยับไว้บนพรม แล้วลุกเดินกลับไปครัว (ทางขวา)
- ต่อเนื่อง: ตำแหน่งกล่องจากนี้ไปตายตัว = บนพรมหน้าโซฟา

**4.2 · 0:45.5–0:48.5** — สงสัย
- C: หยุดกึก จ้องกล่อง เอียงหัว "?" เดินเข้าไปช้า ๆ ยืดคอดม แตะกล่องด้วยเท้า กล่องโยก

**4.3 · 0:48.5–0:51** — มุดแล้วกระโดด
- C: เท้าหน้าเกาะขอบ มุดหัวลงไป เหลือก้นกับหางกระดิกอยู่ข้างนอก → กระโดดลงไปทั้งตัว กล่องกระเด้ง กระดาษปลิว

**4.4 · 0:51–0:55** — มุมมองจากในกล่อง
- D: กล้องอยู่ก้นกล่องมองขึ้น ผนังกระดาษลังเป็นกรอบสี่ด้าน หน้าแมวโผล่เข้ามา
- C: ตบกระดาษ → ย่อตัวส่ายก้น → กระโจน → กลิ้งหงายกอดกระดาษ → งับเบา ๆ มีเส้นเสียงกรอบแกรบ

**4.5 · 0:55–1:02** — หีบสมบัติ
- C: กล่องโยกไปมา ก้อนกระดาษเด้งออกมา หางชูโผล่ขอบกล่องแกว่งไปมา → โผล่หัวออกมามีกระดาษติดหัว ตาเป็นดาว
- D: Medium นอกกล่อง ประกายวิบ ๆ ที่ขอบกล่องเหมือนหีบสมบัติ

### SCENE 05 — LITTLE SCARE (1:02–1:12) · ตกใจเล็กน้อย

### SCENE 06 — TOGETHER (1:12–1:30+) · อบอุ่น ผูกพัน

> ช็อตสุดท้ายถอยกว้างจนเห็นทั้งห้อง ซึ่งกว้างพอจะเห็นหัวเจ้าของที่นั่งอยู่ — เจ้าของจึง**ถือหนังสือบังหน้า**อ่านอยู่บนโซฟา (ยังไม่เปิดเผยหน้าตามบรีฟ) · จบด้วยค้างภาพ 2 วินาทีแล้วค่อย ๆ มืดลง

**6.6 · 1:28–1:30 (+ค้าง 2 วิ)** — ภาพค้าง: หางขยับเบา ๆ มือลูบช้า ๆ แมวหลับตามีความสุข

## F. Animation Direction — ภาษากายของน้องส้ม

| ส่วน | อารมณ์ → ท่า |
|---|---|
| **หู** | สบาย = ตั้งปกติ กระดิกเป็นระยะ · ได้ยินเสียง = หมุน/กระดิกข้างเดียวก่อน แล้วตั้งชัน · ถูกลูบ = ลู่ตามมือ · ตกใจ = ลู่แบนติดหัว |
| **หาง** | นอน = พันรอบตัว ปลายกระดิกช้า ๆ · รออาหาร = กระดิกซ้ายขวาตรงจังหวะเพลง · ตื่นเต้น = ชูตั้ง ปลายสั่น · ตกใจ = ฟูพอง · รำคาญ = สะบัดแรงทีเดียว |
| **ตา** | ง่วง = ปรือครึ่ง · สงสัย = กลมโต + เอียงหัว · มีความสุข = ปิดโค้งยิ้ม · ตกใจ = โตสุด · อยากได้ = ประกายดาว |
| **เดิน** | ก้าวสั้น เด้งขึ้นลงเล็กน้อย หางชูเป็นเครื่องหมายคำถาม |
| **วิ่ง** | ท่าวิ่งของตัวเกม ตัวยืดหดตามก้าว หูเอนไปหลัง |
| **กระโดด** | ย่อตัว → ส่ายก้น (แอนติซิเพชัน) → พุ่งเป็นเส้นโค้ง → ลงพื้นตัวแบนแล้วเด้งคืน |
| **ดม** | ยืดคอยื่นไปข้างหน้า ตัวเอนตาม จมูกกระดุกเป็นจังหวะเร็ว ๆ |
| **เล่น** | ตบด้วยเท้าหน้าเร็ว ๆ · กระโจนใส่ · กลิ้งหงายกอดของ · งับเบา ๆ |
| **ตกใจ** | แข็งค้างทันที (ไม่มีช่วงเปลี่ยนท่า) → ขนพอง → ค่อย ๆ ถอย |
| **คลอเคลีย** | หลับตา เอียงหัวถูเข้าหามือ ตัวเอนตาม มี "~" ลอย |
| **นอน** | หมอบขด ตัวขยับขึ้นลงตามลมหายใจช้า ๆ มี "z" ลอยเป็นระยะ |

**กฎ:** ทุกท่ามีช่วงเตรียม → ท่าหลัก → ตามแรง (anticipation → action → follow-through) ·
ห้ามยืนนิ่งร้องเพลง · ห้ามทำท่าซ้ำติดกันสอง Shot · ทุก Scene ต้องเป็น **เหตุ → การกระทำ → ปฏิกิริยา → ทางเชื่อม**
