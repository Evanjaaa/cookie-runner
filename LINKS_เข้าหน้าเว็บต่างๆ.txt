┌─ 1. เว็บจริง (ที่คนเล่นเข้าได้) ──────────────────────────────────────┐

  หน้าเกม (หน้าบ้าน)      https://meowzing.vercel.app/
  หลังบ้าน (แอดมิน)       https://meowzing.vercel.app/admin.html
  โต๊ะออกแบบด่าน          https://meowzing.vercel.app/editor.html

  * ทั้งสามหน้าเช็กแล้วเปิดได้จริง (ตอบ 200)
  * cookie-runner.vercel.app ไม่ใช่ของเรา เป็นเว็บคนอื่นที่ชื่อชนกัน อย่าสับสน


┌─ 2. ⚠ เว็บจริงยังเป็นเวอร์ชันเก่า ───────────────────────────────────┐

  ของที่ขึ้นเว็บอยู่ตอนนี้เป็นของวันที่ 13 ก.ย. 2026 (ประมาณคอมมิต 38)
  ยังไม่มี: ระบบพรสวรรค์ / คลิปเปิดเกม / ปุ่มท่าพิเศษ

  โค้ดล่าสุด (คอมมิต 39, 40) push ขึ้น GitHub แล้ว แต่ Vercel ยังไม่ได้ deploy
  แปลว่าโปรเจกต์นี้ deploy ด้วยมือ ไม่ได้ต่อ auto-deploy กับ GitHub ไว้

  สั่ง deploy เอง:
      npm run build
      npx vercel --prod


┌─ 3. รันในเครื่องตัวเอง ──────────────────────────────────────────────┐

  npm install            ติดตั้งครั้งแรกครั้งเดียว
  npm run dev            เปิด http://localhost:5173
  npm run build          สร้างไฟล์จริงลงโฟลเดอร์ dist/
  npm run preview        ลองของที่ build แล้ว (ควรทำก่อน deploy ทุกครั้ง)

  เปิดจากมือถือในวง Wi-Fi เดียวกัน:
      npm run dev -- --host
      แล้วเปิด http://<ไอพีเครื่องคอม>:5173   (ไอพีเปลี่ยนได้เรื่อย ๆ ดูที่ ipconfig)

  เปลี่ยนพอร์ต (ที่ใช้ทำงานกันประจำคือ 5199):
      npm run dev -- --port 5199
      แล้วเปิด http://localhost:5199


┌─ 4. หน้าต่าง ๆ ในเกม ────────────────────────────────────────────────┐

  ── 4.1 หน้าที่ขึ้นเว็บจริงด้วย (ต่อท้าย URL ได้ทั้งเว็บจริงและ localhost) ──

  /                      หน้าเกมหลัก
  /admin.html            หลังบ้าน — ดูผู้เล่น จดหมาย สถิติ
  /editor.html           โต๊ะออกแบบด่าน — ลากวางสิ่งกีดขวางกับของกิน แล้วคัดลอกโค้ด

  ── 4.2 หน้าทดสอบตอนพัฒนา (เปิดได้เฉพาะตอน npm run dev เท่านั้น) ──
  ตั้งใจไม่ให้ขึ้นเว็บจริง: ไม่ได้อยู่ใน rollupOptions.input ของ vite.config.js
  จึงไม่ถูก build — บนเว็บจริงจะเปิดไม่เจอ
  ลิงก์ข้างล่างใช้พอร์ต 5199 (ถ้ารัน npm run dev เฉย ๆ เปลี่ยนเป็น 5173)

  /cat-lab.html          ห้องทดสอบท่าน้องแบบใหม่ — เลือกท่า หยุดค้างท่า
                         ลากหลอดเวลาแบบวิดีโอ ซูมดูหน้า เปลี่ยนสีแมว
                         http://localhost:5199/cat-lab.html
  /intro-preview.html    พรีวิวคลิปเปิดเกม (คลิปที่วาดด้วยโค้ด)
                         http://localhost:5199/intro-preview.html
  /mv.html               หน้าทำงานของ MV เพลงน้องแมว
                         http://localhost:5199/mv.html
  /sound-test.html       ทดสอบเสียง — หาว่าเสียงหายที่ชั้นไหน (ใช้กับ iPhone)
                         http://localhost:5199/sound-test.html

  เปิดจากมือถือ: แทน localhost ด้วยไอพีเครื่องคอม เช่น
      http://192.168.1.119:5199/cat-lab.html   (ไอพีเปลี่ยนได้ ดูที่ ipconfig)

    supabase/schema.sql   ตารางหลัก

    supabase/admin.sql    สิทธิ์หลังบ้าน

  ตัวอย่างหน้าตาไฟล์ดูได้ที่ .env.example

    ไม่งั้นเว็บจริงจะเล่นได้แต่ไม่มีบัญชีและไม่มีอันดับ


┌─ 8. อยากตรวจเองว่าลิงก์ไหนยังใช้ได้ ────────────────────────────────┐

  เช็กว่าเว็บเปิดได้ไหม (200 = ได้ / 404 = ไม่มี):
      curl -s -o /dev/null -w "%{http_code}" https://meowzing.vercel.app/

  เช็กว่าเว็บจริงอัปเดตหรือยัง (นับคำว่า พรสวรรค์ ถ้าได้ 0 = ยังเก่า):
      curl -s https://meowzing.vercel.app/ | grep -c "พรสวรรค์"

  เช็กว่าโค้ดในเครื่องตรงกับ GitHub ไหม (0 0 = ตรงกัน):
      git rev-list --left-right --count origin/main...HEAD
