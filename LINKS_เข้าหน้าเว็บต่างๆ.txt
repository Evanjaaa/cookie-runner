  เช็กซ้ำ 30 ต.ค. 2026: เว็บจริงยังเป็นตัวเก่าอยู่ (ยังไม่มี Cinematic · ยังไม่มีหน้าเมือง)
  โค้ดล่าสุดใน GitHub = คอมมิต 88 (เว็บจริงยังไม่ได้ deploy)
  โปรเจกต์นี้ deploy ด้วยมือ ไม่ได้ต่อ auto-deploy กับ GitHub ไว้
  งานค้างยังเยอะ — ตั้งใจเก็บไว้ deploy ตอนไฟนอล

  สั่ง deploy เอง (เจ้าของโปรเจกต์ทำเอง):
      npm run deploy:test   ลิงก์ทดสอบ meowzing-test.vercel.app (เว็บจริงไม่เปลี่ยน)
                            = deploy แบบ Preview แล้วผูกชื่อคงที่ให้ (tools/deploy-test.mjs)
                            สั่งเสร็จปิดคอมได้เลย เปิดลิงก์บน iPad ได้ทุกที่
      npm run deploy        ขึ้นเว็บจริง (= vercel deploy --prod --scope evanjaaas-projects)
                            หรือกด "Promote to Production" ที่ deploy ทดสอบในหน้า Vercel
      (ไม่ต้อง npm run build ก่อน — Vercel build เองบนเซิร์ฟเวอร์)

  เวอร์ชันเก่าไม่หาย: ทุกครั้งที่ deploy มีลิงก์ของตัวเองในหน้า Vercel → Deployments
  ขึ้นเว็บจริงแล้วไม่ชอบ → กด Instant Rollback ย้อนได้ทันที


┌─ 3. รันในเครื่องตัวเอง ──────────────────────────────────────────────┐

  npm install            ติดตั้งครั้งแรกครั้งเดียว
  npm run dev            เปิด http://localhost:5173
  npm run build          สร้างไฟล์จริงลงโฟลเดอร์ dist/
  npm run preview        ลองของที่ build แล้ว (เปิด http://localhost:4173)

  เปิดจากมือถือ / iPad ในวง Wi-Fi เดียวกัน:
      npx vite --host 0.0.0.0 --port 5173                 (แบบพัฒนา — มีหน้าทดสอบ)
      npx vite preview --host 0.0.0.0 --port 4173         (แบบ build แล้ว — เร็ว เหมือนเล่นจริง)
      แล้วเปิด http://<ไอพีเครื่องคอม>:5173 หรือ :4173

  ไอพีเครื่องคอมล่าสุด (30 ต.ค. · ต่อ Wi-Fi บ้าน): 192.168.1.34   (ต่อฮอตสปอตมือถือเคยได้ 172.20.10.2)
  ไอพีเปลี่ยนตามเน็ตที่ต่อ ดูที่ ipconfig → บรรทัด IPv4 ใต้ "Wireless LAN adapter Wi-Fi"
  (ตัวอื่น เช่น 192.168.56.x / 192.168.137.x / 26.x เป็นการ์ดเครือข่ายจำลอง ใช้กับมือถือไม่ได้)

  * มือถือ/iPad ใช้ :4173 จะลื่นกว่า :5173 มาก (แบบพัฒนาโหลดไฟล์ทีละชิ้น)
    แต่ :4173 ต้อง npm run build ใหม่ทุกครั้งที่แก้โค้ด และไม่มีหน้าทดสอบ

      git fetch && git rev-list --left-right --count origin/main...HEAD
