MeowZing — คีย์ลัดหน้าออกแบบด่าน (editor.html)
=====================================================
แบบเดียวกับ Blender · ในหน้าออกแบบกด ? หรือ F1 (หรือปุ่ม "⌨ คีย์ลัด" บนแถบบน) เปิดดูได้ตลอด
คีย์ลัดไม่ทำงานตอนพิมพ์อยู่ในช่องกรอก (ชื่อท่อน ตัวเลข ฯลฯ)


ย้าย / ยืด (แบบ Blender)
-----------------------------------------------------
G                 ย้ายชิ้นที่เลือก — ของเดินตามเมาส์ทันที ไม่ต้องกดค้าง
S                 ยืด/หด ตามระยะเมาส์ (ความกว้างหลุม-พื้นลอย หรือจำนวนเม็ด/หนามในแถว)

ระหว่างกด G หรือ S อยู่:
  คลิกซ้าย / Enter / Space   ยืนยัน
  คลิกขวา / Esc              ยกเลิก — ของกลับที่เดิมเป๊ะ
  X                          (G) ล็อกให้ขยับแนวนอนอย่างเดียว   กดซ้ำ = ปลดล็อก
  Y                          (G) ล็อกให้ขยับแนวตั้งอย่างเดียว   (ของกิน และพื้นลอย = ปรับความสูง)
  พิมพ์ตัวเลข                (G) ระยะเป๊ะเป็นพิกเซล   (S) ตัวคูณ
                             Backspace ลบตัวเลข · -  สลับบวก/ลบ
  Ctrl ค้าง                  (G) ไม่ดูดเข้าจุดกด วางตรงไหนอยู่ตรงนั้น
  Shift ค้าง                 ขยับละเอียด ช้าลง 10 เท่า

ตัวอย่าง:
  G 4 0 Enter        ขยับไปทางขวา 40px
  G - 4 0 Enter      ขยับไปทางซ้าย 40px
  G Y 2 0 Enter      ยกแถวพื้น / พื้นลอยขึ้น 20px
  S 2 Enter          ยืดเป็น 2 เท่า
  S 0 . 5 Enter      หดเหลือครึ่งเดียว

ทั้งหมดนับเป็นการย้อนกลับก้าวเดียว — Ctrl+Z ทีเดียวกลับที่เดิม


เลือก / แก้ชิ้น
-----------------------------------------------------
คลิก               เลือกชิ้น (คลิกค้างแล้วลากก็ยังใช้ได้เหมือนเดิม)
Tab                เลือกชิ้นถัดไป (เรียงซ้ายไปขวา) แล้วเลื่อนจอไปหา
Shift+Tab          เลือกชิ้นก่อนหน้า
Esc                เลิกเลือกทั้งหมด
Shift+D            ทำสำเนาแล้วเข้าโหมดย้ายทันที (เหมือน Blender) — คลิกวางได้เลย
Ctrl+D             ทำสำเนาวางถัดไปทางขวา 60px
X / Delete         ลบที่เลือกทั้งหมด รวมทั้งกลุ่ม (Ctrl+Z เอาคืนได้)
← →                ขยับทีละ 1px   ·   Shift + ← →  ทีละ 10px


เลือกหลายชิ้น / รวมกลุ่ม
-----------------------------------------------------
Shift+คลิก         เลือกเพิ่มทีละชิ้น (คลิกซ้ำ = เอาออก) ปล่อย Shift แล้วยังเลือกค้างอยู่
                   ระหว่างเลือกหลายชิ้น: ลากชิ้นไหนก็ย้ายทั้งหมด · G / ← → / Delete ทำพร้อมกันทุกชิ้น
Ctrl+J             รวมที่เลือกเป็นกลุ่ม — ต่อไปคลิกชิ้นไหนในกลุ่มก็เลือกทั้งกลุ่ม ลากก็ย้ายทั้งกลุ่ม
                   จับกลุ่มเพิ่ม: คลิกกลุ่มเดิม + Shift+คลิกชิ้นใหม่ แล้วกด Ctrl+J
Ctrl+K             ยกเลิกกลุ่ม (ทุกชิ้นกลับมาย้ายอิสระ)
ลากขึ้นลง (กลุ่ม)   ปรับความสูงทั้งกลุ่มได้ ถ้าทุกชิ้นปรับความสูงได้ (พื้นลอย / ของกิน)
                   มีชิ้นที่ปรับไม่ได้ (หนาม ลัง หลุม ฯลฯ) = ขึ้นแจ้งเตือน ลากได้แค่ซ้าย-ขวา · G ก็ใช้กติกาเดียวกัน
คลิกขวา            เมนู: รวมกลุ่ม / จับกลุ่มเพิ่ม / ยกเลิกรวมกลุ่ม / ลบ / เลิกเลือก
Alt+ลาก            ย้ายชิ้นเดียวในกลุ่ม โดยไม่ลากทั้งกลุ่ม
ลบชิ้นเดียวในกลุ่ม  Ctrl+K แยกกลุ่มก่อน แล้วค่อยลบ

มุมมอง
-----------------------------------------------------
F / Numpad .       เลื่อนจอไปที่ชิ้นที่เลือก
Home               กลับไปต้นท่อน
ลูกกลิ้งเมาส์       เลื่อนจอซ้าย-ขวา
คลิกกลางค้าง        ลากเลื่อนจอ (คลิกค้างที่ที่ว่างก็ได้)
Space              เล่น / หยุด การวิ่งทดสอบ


ทั่วไป
-----------------------------------------------------
Ctrl+Z                    ย้อนกลับ
Ctrl+Shift+Z / Ctrl+Y     ทำซ้ำ
? / F1                    เปิด/ปิดแผงคีย์ลัด
