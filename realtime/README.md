# ห้องออนไลน์ปราสาทแมวเหมียว (Cloudflare)

เซิร์ฟเวอร์เล็ก ๆ ที่ทำให้ผู้เล่นเห็นแมวของกันและกันในปราสาท — Cloudflare Worker + Durable Object (แผนฟรีใช้ได้)

- 1 ห้อง = ทั้งปราสาท 3 ชั้น ไม่เกิน 20 ตัว · เต็มแล้วเกมย้ายไปห้องถัดไปเอง (castle-2, castle-3 …)
- ส่งเฉพาะตอนสถานะเปลี่ยน (เริ่มเดิน หยุด หัน กระโดด ลงพื้น นั่ง ทำท่า เปลี่ยนชั้น) + ย้ำตำแหน่งทุก ~1.5 วิตอนเดิน
- ห้องเงียบ = หลับ ไม่คิดเวลา (WebSocket Hibernation)
- โค้ดเซิร์ฟเวอร์: `src/index.js` · ฝั่งเกม: `src/town/online.js` + หัวข้อ "ออนไลน์ในปราสาท" ใน `src/town/main.js`

## ลองในเครื่อง (ไม่ต้องล็อกอิน Cloudflare)

```
cd realtime
npm install        # ครั้งแรกครั้งเดียว
npm run dev        # → ws://localhost:8787  (มือถือในวง Wi-Fi เดียวกัน: ws://<IP คอม>:8787)
```

แล้วเปิดเกมด้วย `npm run dev` ที่โฟลเดอร์หลักตามปกติ — ตอนพัฒนาเกมต่อ `ws://<เครื่องเดียวกับหน้าเว็บ>:8787` เอง
เปิด `town.html?spot=hall` สองแท็บ (หรือคอม + มือถือ) จะเห็นแมวอีกตัวเดินอยู่ในปราสาท

## ขึ้นจริง (เจ้าของบัญชีทำเอง)

1. ครั้งแรก: Cloudflare dashboard → Workers & Pages → ตั้งชื่อ subdomain ของ `workers.dev`
2. `cd realtime` แล้ว `npx wrangler login` (เปิดเบราว์เซอร์ให้กดอนุญาต)
3. `npm run deploy` → ได้ที่อยู่แบบ `https://meowzing-castle.<ชื่อ>.workers.dev`
4. Vercel → Settings → Environment Variables เพิ่ม `VITE_CASTLE_WS` = `wss://meowzing-castle.<ชื่อ>.workers.dev`
   (ติ๊ก Preview ด้วยถ้าจะลองบนลิงก์ทดสอบ) แล้ว deploy เกมใหม่
   — ไม่ตั้งตัวนี้ = เกมจริงปิดออนไลน์ เล่นคนเดียวเหมือนเดิม

## ตรวจล็อกอิน (สมาชิก / ผู้มาเยือน)

ห้องถาม Supabase เองว่าตั๋วล็อกอินของแต่ละคนเป็นใคร ไม่เชื่อชื่อจากเครื่องผู้เล่น
- **สมาชิก** (ผูกอีเมลแล้ว): ชื่อดึงจากตาราง `players` เอง ปลอมชื่อไม่ได้ · ป้ายชื่อม่วงเข้ม · (แชตขั้นต่อไป) พิมพ์คุยได้
- **ผู้มาเยือน / ไม่ล็อกอิน**: เข้าห้อง เดินเล่น ทำท่าได้ · ป้ายชื่อเทาม่วงอ่อน · พิมพ์คุยไม่ได้ (ผู้ใช้ตัดสิน 8 พ.ย. 2026)

ต้องบอกห้องว่าโปรเจกต์ Supabase อยู่ไหน — ค่าเดียวกับ `VITE_SUPABASE_URL` / `VITE_SUPABASE_ANON_KEY` ของเกม (เจ้าของบัญชีใส่เอง):
- ขึ้นจริง: `npx wrangler secret put SUPABASE_URL` แล้ว `npx wrangler secret put SUPABASE_ANON_KEY` (วางค่าตอนมันถาม)
- ลองในเครื่อง: สร้างไฟล์ `realtime/.dev.vars` (ไม่ขึ้น git) สองบรรทัด `SUPABASE_URL=...` กับ `SUPABASE_ANON_KEY=...`

ไม่ใส่ = ทุกคนเป็นผู้มาเยือน (เข้าห้อง เดินเล่นได้ปกติ แค่ยังไม่มีใครเป็นสมาชิก)

## ที่นั่ง

ห้องจองที่นั่งให้: ช่องเดียวกันนั่งได้ทีละตัว ใครถึงก่อนได้ก่อน · เกมเลือกช่องว่างที่ใกล้สุดให้เอง · เต็มทุกช่อง = ขึ้นข้อความบอก

## ค่าใช้จ่าย (แผนฟรี)

- คำขอ 100,000 ต่อวัน · ข้อความ WebSocket ขาเข้านับ 20 ข้อความ = 1 คำขอ · ขาออกไม่คิด
- ผู้เล่นหนึ่งคนเดินในปราสาทส่งราว 1 ข้อความต่อวินาที → 20 คนเดินตลอดวันยังอยู่ในโควตา

## แชตแยกชั้น

- ข้อความไปถึงเฉพาะแมวที่อยู่ชั้นเดียวกัน · ขึ้นเป็นฟองบนหัว + กล่องดูย้อนหลังในแผงแชต (ปุ่ม "แชต" ข้างป้ายจำนวนแมว · คอมกด T)
- ทุกคน: ประโยคสำเร็จรูป 16 แบบ + สติกเกอร์ 12 แบบ (ส่งแค่รหัส — `PRESETS` ใน `src/town/chat.js` · `STICKERS` ใน `src/town/stickers.js`)
- สมาชิก: พิมพ์เองได้ ไม่เกิน 60 ตัว · ห้องกรองคำหยาบ (ไทย/อังกฤษ แม้เว้นวรรค/ลากเสียง) ลิงก์ เบอร์โทร ข้อความซ้ำใน 10 วิ (`textProblem` ใน `src/index.js`)
- ส่งได้ 3 ข้อความติดกัน แล้วเติม 1 ข้อความทุก 1.5 วิ
- แตะข้อความของคนอื่นในกล่องย้อนหลัง = **ซ่อนข้อความคนนี้** (จำในเครื่อง) หรือ **รายงาน** (แตะสองครั้ง → เข้ากล่องแจ้งปัญหาเดิม `bug_reports` หมวด "แชตปราสาท" พร้อมชื่อ รหัสผู้เล่น ข้อความล่าสุด แล้วซ่อนให้เลย) — ดูได้ในหลังบ้านหน้าแจ้งปัญหา
